# OS Simulator - Java Project

A simple Operating System simulator demonstrating process management, CPU scheduling, memory management, and file system operations.

## Features
✅ Process Management with PCB
✅ CPU Scheduling Algorithms (FCFS, SJF, Priority, Round Robin)
✅ Memory Management (First Fit, Best Fit, Worst Fit)
✅ File System Simulation
✅ Producer-Consumer Problem Simulation
✅ Graphical User Interface (Swing)
